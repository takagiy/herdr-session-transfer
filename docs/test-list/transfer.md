# Transfer

What the user sees after picking "Transfer to <harness>" on a pane.

- [x] When the user transfers a Claude Code pane to Codex, the pane can continue the same conversation in Codex.
- [x] When the pane runs no agent this plugin knows, the user can see why nothing happened and the pane can stay as it was.
- [x] When herdr does not know which conversation the pane holds, the user can see why nothing happened and the pane can keep its agent.
- [x] When the agent is the pane's own process rather than a program started from its shell, the user can see why nothing happened and the pane can keep its agent.
- [x] When the conversation cannot be copied to the target harness, the user can see why and the pane can keep its agent.
- [x] When the pane cannot start the target harness after its agent stopped, the user can see the command that continues the conversation.
