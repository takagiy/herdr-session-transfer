# Picker

The popup where the user chooses the harness to transfer to.

- [x] When the picker opens over a Claude Code pane, the user can choose among the listed harnesses other than Claude Code.
- [x] When the user moves down and confirms, the picker can choose the highlighted harness.
- [x] When the user presses a harness's number, the picker can choose that harness.
- [x] When the user presses Escape, the picker can close without choosing.
