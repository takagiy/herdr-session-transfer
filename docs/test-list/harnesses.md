# Harnesses

The table that maps herdr's agent names to txcript harnesses.

- [x] When herdr names an agent the table lists, the table can give its txcript harness.
- [x] When herdr names an agent the table does not list, the table can report that it has no harness for it.
- [x] When the picker lists a harness, the table can give its display name.
